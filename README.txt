PUBLISH FREE WITH GITHUB PAGES
1. Sign in to https://github.com/mohamedkhaledmahmoud97-ux
2. Create a PUBLIC repository named: card
3. Upload the contents of this package to the repository root.
   Keep the assets folder and its two files together.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment. Expected address:
   https://mohamedkhaledmahmoud97-ux.github.io/card/

After the public page is live, test all buttons and create a static QR code
for the final public URL. Do not print a QR code before confirming the page URL.
